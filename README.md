# NexStep

NexStep is a professional resume-based job recommendation platform. The application allows users to create an account, upload their resume, extract skills and experience, and receive personalized job recommendations with match scores and application tracking.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python Flask
- **Database:** MySQL (Planned)
- **ML / NLP:** Python ML (Planned for future release)

---

## Current Development Stage

**Stage 2: Frontend Foundation & Landing Page Setup**
- Flask backend configured with status endpoint (`GET /`)
- Responsive modern landing page built in `Frontend/` (`index.html`, `css/style.css`, `js/script.js`)

---

## How to Run the Project (Single Command)

Open a terminal in the project root (`d:\antigravity\NexStep`):

```powershell
python run.py
```

This starts both servers simultaneously:
* **Frontend Landing Page:** [http://127.0.0.1:3000/](http://127.0.0.1:3000/)
* **Backend API Status:** [http://127.0.0.1:5000/](http://127.0.0.1:5000/)
